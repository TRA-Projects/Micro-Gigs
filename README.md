# Micro-Gigs

Micro-Gigs is a modern web platform that connects clients with freelancers through short-term, task-based opportunities. The system enables clients to publish micro tasks, receive applications, assign freelancers, track progress, manage file attachments, and review completed work in a secure and efficient environment.

The project follows a clean layered architecture using **ASP.NET Core Web API**, **Entity Framework Core**, and **SQL Server**, ensuring scalability, maintainability, and high performance. 


## Features

- User Authentication & Authorization (JWT)
- Publish and Manage Micro Tasks
- Browse and Search Available Tasks
- Apply for Tasks
- Accept or Reject Applications
- Task Assignment & Progress Tracking
- File Attachments
- Ratings & Reviews
- Dashboard for Clients and Freelancers


## Tech Stack

- ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server
- JWT Authentication
- REST API
- Swagger/OpenAPI
- Git & GitHub


## Project Goal

The goal of Micro-Gigs is to provide a reliable platform where clients can quickly outsource small tasks while freelancers can discover opportunities, submit proposals, complete assignments, and build their professional reputation through ratings and reviews. 


## Team Project

This project was developed collaboratively using **Git & GitHub**, following a professional workflow with feature branches, pull requests, and code reviews to ensure high-quality, maintainable code.
